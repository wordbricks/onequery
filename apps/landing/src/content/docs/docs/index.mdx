OneQuery gives developers and agents one governed path to approved data sources. Connect a source once, use an identifier like `postgres://warehouse`, and keep raw credentials out of prompts, scripts, and agent environments.

## Fast Path

1. [Get started](/docs/getting-started/) with the CLI and choose a shared, hosted, or local server path.
2. Connect one read-only source.
3. Run one query or provider API call.
4. Give agents only the source identifiers they need.
