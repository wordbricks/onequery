## Mental Model

- OneQuery is an access layer, not a database, warehouse, or agent framework.
- A server or local gateway holds credentials; prompts and agent runtimes do not.
- Agents receive source identifiers like `postgres://warehouse`, then OneQuery enforces the request path.
- Audit history shows which source was used, what was requested, and which workflow made the request.
